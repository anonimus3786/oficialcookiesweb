10 вопросов для подготовки 🍪
← Назад
1
Что такое переменная?
+

Переменная — это именованная область памяти, в которой хранится какое-либо значение. Переменной можно присвоить значение, изменить его и использовать в дальнейшем коде.

Пример на JavaScript:

let name = "Марк";
let age = 25;
2
Что такое функция?
+

Функция — это блок кода, который выполняет определённую задачу. Функцию можно вызывать много раз, передавать ей аргументы и получать результат.

Пример:

function greet(name) {
  return "Привет, " + name + "!";
}
console.log(greet("Марк"));
3
Что такое локальный сервер?
+

Локальный сервер — это сервер, который запускается на твоём компьютере (локально) и используется для разработки и тестирования сайтов или приложений. Он доступен по адресу localhost или 127.0.0.1.

Примеры: XAMPP, OpenServer, Live Server в VS Code, Node.js.

4
Что такое цикл?
+

Цикл — это конструкция, которая позволяет повторять один и тот же блок кода несколько раз, пока выполняется определённое условие.

Виды циклов: for, while, do...while.

for (let i = 0; i < 5; i++) {
  console.log(i);
}
5
Что такое библиотека?
+

Библиотека — это набор готового кода (функций, классов, методов), который можно подключить к своему проекту и использовать, чтобы не писать всё с нуля.

Примеры: jQuery, React, Lodash, Pandas (Python).

6
Напиши цикл отсчёта от 0 до 10.
+

Пример на JavaScript:

for (let i = 0; i <= 10; i++) {
  console.log(i);
}

Этот цикл выведет числа от 0 до 10 включительно.

7
Напишите переменную, имеющую булево значение.
+

Пример:

let isGameReady = true;
let isPaused = false;

Булево значение — это true (истина) или false (ложь).

8
Напишите объект, имеющий внутри ключ color со значением red.
+

Пример:

let myObject = {
  color: "red"
};

Обратиться к значению можно так: myObject.color → вернёт "red".

9
Напишите массив, имеющий внутри себя значения: 1, красный, истинно, ложь, 3.14.
+

Пример:

let myArray = [1, "красный", true, false, 3.14];

Массив может хранить значения разных типов — числа, строки, булевы значения и т.д.

10
Напишите все виды данных переменных.
+

Основные типы данных в JavaScript:

  • Number — числа (целые и дробные): 42, 3.14
  • String — строки: "Привет"
  • Boolean — логический тип: true / false
  • Undefined — переменная объявлена, но значение не присвоено
  • Null — намеренное отсутствие значения
  • Object — объекты: { key: "value" }
  • Array — массивы: [1, 2, 3]
  • Symbol — уникальный идентификатор
  • BigInt — для очень больших чисел
